# P5 · 状态配对反事实重渲染与 VLA 因果不变性训练

**CF-IRM: Closing the Robustness Gap of VLA Models with State-Matched Counterfactual Re-Rendering**

- 目标会议：CoRL 2027（主，机器人味最浓）；备选 ICLR 2028
- 风险等级：中（审稿定性风险 > 技术风险）｜ 总算力：60–100 GPU 天 ｜ 墙钟：10–14 周

---

## 1. 摘要

LIBERO-Plus 的系统性诊断表明：当前 VLA 模型（含 OpenVLA-OFT、π0 系）在相机视角、
光照、桌面纹理、干扰物等**非因果扰动**下成功率崩塌达 50 点以上——但该工作止于诊断，
没有给出训练端治疗。标准对策（域随机化、像素增广）向模型展示更多样的观测,却从不
告诉模型**哪些变化不应该改变动作**：增广是无监督的分布扩张，不变性只能被间接祈祷。
本文利用仿真器的一项被忽视的能力——**状态配对重渲染**：对 LIBERO 每个训练帧，冻结
物理状态（物体位姿、机器人构型），只干预滋扰因子（光照/纹理/视角/干扰物）重新渲染，
得到物理上不可能采集到的反事实观测对 (o, o')，其最优动作严格相同。训练时施加双重
不变性约束：VLM 融合特征上的跨对对比对齐 + 流匹配速度场的跨对一致。我们将该目标
形式化为干预分布上的不变风险最小化，并给出最坏情况扰动风险 ≤ 干净风险 + 不变性
残差 × 扰动强度的分解，使"鲁棒性从哪里来"成为可测量命题。在 LIBERO-Plus 全部七类
扰动上，预注册预测为：扰动-干净成功率差距相对最强增广基线缩小 ≥50%，干净成功率
损失 ≤2 点，且各扰动类的鲁棒性增益与该类表征不变度（CKA）提升呈显著正相关——后者
若不成立，则"鲁棒性经由不变表征获得"的机制假设被证伪，方法退化为另一种数据增广。

## 2. 科学问题

模仿学习目标 E[(π(o)−a*)²] 对"o 中哪些因子与 a* 有因果关系"不施加任何约束。
设观测生成过程 o = g(s, n)：s 为任务相关状态（物体/机器人位姿），n 为滋扰因子
（光照、纹理、视角、无关物体）。最优策略满足 π*(g(s,n)) = π*(g(s,n')) 对一切
n,n'——这是一个**在标准数据里永远没有监督信号的恒等式**，因为真实采集中 (s,n)
从不独立变化（同一演示里光照与状态同时在变，跨演示则 s 也变了）。
科学问题：显式构造 n 的干预对并施加不变性约束，相比只扩张 n 边缘分布的增广，
是否以及为何能带来质变的分布外鲁棒性？

**为什么现在做**：LIBERO-Plus（[arXiv:2510.13626](https://arxiv.org/abs/2510.13626)）
2025 年 10 月才把问题定量化（含逐因子扰动协议），治疗端窗口正开着；且 LIBERO 基于
MuJoCo/robosuite，状态配对重渲染工程上是"改渲染参数重跑 render"的量级，不需要
训练任何生成模型——这是别人用扩散编辑器路线（有幻觉、有物理不一致）绕远路时，
我们用仿真器直接拿到**完美反事实**的窗口期。

**撞车风险评估**：搜索未发现"状态配对重渲染 + 不变性约束 + VLA"的组合。最接近的
危险是有人把 LIBERO-Plus 的扰动直接当训练增广使用（"train on the test
distribution"式的粗暴解法）——这必须列为我们的重要基线（B4），并靠两点区分：
(a) 我们的评测含 held-out 扰动因子（训练时不见的因子类），检验的是不变性机制的
外推而非记忆；(b) 机制指标（CKA 不变度）把"为什么有效"讲清楚。

## 4. 方法

### 4.1 反事实工厂（A800，纯数据工程）

对训练集每个 (episode, 帧) 从 HDF5 恢复 MuJoCo 状态 → 干预采样 n' ~ P(n)
（光照方向/强度、桌面与背景纹理、相机外参小扰动、干扰物增删——干扰物增删需
碰撞检查以保证不接触任务物体，否则破坏 s 不变性）→ 重渲染得 o'。每帧 4 个
反事实版本，约 2TB，离线单向运往 A100。**质量保证协议**：抽样 1% 用状态哈希
校验 s 严格一致 + 人工目检 500 帧；干扰物碰撞检查失败率入库。

### 4.2 训练目标（A100）

```
L = L_FM(o, a*) + λ₁·L_align + λ₂·L_consist
L_align  = InfoNCE(h(o), h(o'))          # vlm_features 池化后的跨对对齐（负样本=批内他样本）
L_consist = E_t‖v_θ(x_t, t | o) − v_θ(x_t, t | o')‖²   # 同一噪声/时间下速度场跨对一致
```

L_consist 是比特征对齐更强的约束（直接约束策略输出而非中间表征），二者关系本身是
消融点。理论分解（证明义务较轻，主要是三角不等式+Lipschitz 论证）：
最坏扰动风险 ≤ 干净风险 + C·E‖v(·|o)−v(·|o')‖ + 干预覆盖误差（P(n) 与真实扰动
分布的距离）。第三项诚实指出方法边界：干预分布覆盖不到的扰动类（如物理参数变化）
不在承诺范围内。

### 4.3 与增广的本质区别（论文必须讲透的一段）

等渲染预算下：增广 = 把 (o', a*) 当独立样本加入 ERM；配对 = 额外知道 o 与 o'
的 s 相同。信息论上配对携带严格更多信息；几何上配对约束把解空间从"分别拟合两个
观测"缩到"以相同方式处理两个观测"。预期实验签名：等预算下配对组的扰动差距
显著小于增广组（主消融 A1），且泛化到 held-out 扰动因子的差异更大。

## 5. 红队自我批判

| # | 质疑 | 严重性 | 对策 |
|---|---|---|---|
| R1 | "domain randomization++"定性攻击 | **高（定性级）** | 三层防御：① 等预算配对 vs 非配对主消融（方法核心差异的直接证据）；② held-out 扰动因子外推；③ CKA 机制通道。三者齐备时该攻击不成立 |
| R2 | LIBERO 重渲染管线的工程坑：状态恢复不完全（robosuite 版本、控制器内部状态） | 中 | Phase 0.2 先验证 100 帧的状态往返一致性（重置→重渲→物理量逐项比对）；若 robosuite 不支持完全恢复，退化方案：重放动作序列到目标帧（确定性物理下等价） |
| R3 | 视角扰动改变了图像中机器人位姿的投影，proprio 与视觉的对应关系变化，可能伤害干净性能 | 中 | 视角扰动单独成组消融；幅度阶梯（±5°/±15°/±30°）；proprio 始终不变提供锚 |
| R4 | 结论只在仿真成立，真实机器人的滋扰（真实光照/反射）分布不同 | 中 | scope 限定 + 一个低成本 sim-to-sim 转移实验：LIBERO 训练 → robosuite 另一渲染器（或 Isaac 重实现的子集）评测，检验不变性跨渲染域外推；真机列为 future work |
| R5 | λ₁, λ₂ 调参可能出现不变性-干净性能跷跷板 | 低-中 | 显式画 λ-Pareto 曲线而非单点；预算已含 |
| R6 | 2TB 数据的 IO 成为训练瓶颈 | 低 | 反事实对以 episode 为单位分片打包；dataloader 已是 IterableDataset 流式架构，改造小 |

## 6. 实验设计

### Phase 0：可行性预实验（约 8 GPU 天 + 1 周工程，共 2.5 周）

| 编号 | 实验 | go/no-go |
|---|---|---|
| P0.1 | 在我们的 SimVLA SFT ckpt 上复现 LIBERO-Plus 扰动崩塌（七类各 2 任务 × 20 回合） | 平均差距 ≥25 点 → 问题在本模型上存在，go；<10 点 → SimVLA 意外鲁棒，方向对本代码库无意义，**砍**（或换 OpenVLA-OFT 为主平台） |
| P0.2 | 重渲染管线状态保真验证（R2 对策）+ 每帧渲染耗时测量 → 推算 2TB 工厂总耗时 | 状态往返误差 < 1e-6 且总耗时 <10 天（A800 CPU/GPU 混合）→ go |
| P0.3 | 微型验证：libero_spatial 1 万帧 ×4 反事实，20k 步训练，测两类扰动 | 扰动差距缩小 ≥20%（相对无增广）→ go |

### Phase 1：主实验（约 35 GPU 天，4 周）

- 数据：全量反事实工厂（A800 产出，含四类干预因子；**视角与干扰物各留一个子类
  完全不进训练**，作为 held-out 外推评测）
- 方法组：
  - B1 SimVLA 原版（无增广）
  - B2 像素增广（RandAug/ColorJitter 加强版）
  - B3 非配对域随机化（同渲染预算，o' 作为独立样本）
  - B4 "扰动即增广"（直接用 LIBERO-Plus 式扰动训练，非配对）
  - O1 CF-IRM（配对 + 双约束）
  - O2 CF-IRM 仅特征对齐 / O3 仅速度一致（拆解）
- 评测：干净四套件 + LIBERO-Plus 七类 + held-out 因子；每格 50 trials × 3 seeds
- 外部对照：OpenVLA-OFT 公开权重同评测（只测不训，定位行业水位）

### Phase 2：消融（约 20 GPU 天，2.5 周）

反事实倍数 {1,2,4,8}×；干预因子逐个删除（光照/纹理/视角/干扰物各自贡献）；
λ₁×λ₂ 网格的 Pareto；InfoNCE vs 简单 L2 对齐；负样本设计；
视角幅度阶梯（R3）；数据规模缩放（25%/50%/100% 演示 × 有无反事实——
反事实是否等效于更多演示数据的问题）。

### Phase 3：机制分析（约 10 GPU 天）

- 各扰动类的 CKA 不变度提升 vs 成功率差距缩小的散点与相关（主证伪通道）；
- 逐层不变性传播：干预不变性在 VLM 哪一层建立（对齐约束加在不同深度的消融）；
- 失败案例：不变性约束"过度"的证据搜索（把任务相关变化也抹掉的案例，如目标
  物体颜色恰是任务指令一部分时——"pick the red cup"与纹理干预的冲突处理协议）；
- sim-to-sim 外推实验（R4）。

**Phase 3 第三点是写作时发现的真问题**：指令引用外观属性（颜色/材质）时，
纹理/颜色干预会破坏 s 不变性（"红杯子"被改色后正确动作变了）。工厂协议因此
增加规则：解析指令中的外观指涉词，被指涉物体的对应属性列入 s 保护集不得干预。
这条协议本身要作为方法细节写入论文（审稿人若自己发现而论文没写,是致命伤；
论文先写出来则是严谨性加分）。

## 7. 预注册可证伪结论

1. LIBERO-Plus 七类平均：O1 的扰动-干净差距 ≤ B3 的 50%，干净成功率 ≥ B1 −2 点。
   不成立 → 方法失败。
2. 等预算配对 O1 显著优于非配对 B3（配对机制的直接检验，p<0.05 配对 bootstrap）。
   不成立 → "配对携带额外信息"命题证伪，方法确实只是增广，撤稿级结论。
3. held-out 扰动因子上 O1 仍优于 B3/B4 ≥10 点（外推而非记忆）。
4. 机制通道：七类扰动的 (ΔCKA 不变度, Δ差距缩小) 相关 ρ>0.7。不成立但 1–3 成立
   → 报告"有效但机制未定"，删机制叙事保实证叙事。
