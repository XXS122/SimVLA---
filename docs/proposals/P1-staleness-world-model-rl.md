# P1 · 陈旧感知的世界模型在环强化学习后训练

**SAW-RL: Staleness-Aware World-Model Reinforcement Learning for VLA Post-Training**

- 目标会议：NeurIPS 2027（若算力扩容）；当前判定：**暂缓启动**
- 风险等级：高 ｜ 总算力：300–400 GPU 天（超出双卡合理供给）｜ 墙钟：4–6 个月
- 本文档的作用：完整论证方向价值与暂缓理由，预置好重启条件与设计，避免将来重新调研

---

## 1. 摘要

RL 后训练是当前提升 VLA 泛化的最有效手段，但其两大流派各有结构性缺陷：仿真器
在环流派（SimpleVLA-RL）被锁死在有精确仿真器的任务上；世界模型在环流派（VLA-RFT
等）把世界模型当作**训练一次即冻结**的静态模拟器——当 RL 把策略推离世界模型的训练
分布，模型误差被策略系统性利用（想象空间的 reward hacking），这是该流派公开的
未解问题。让世界模型随策略共同进化是显然的答案，但它在两类真实约束下不可能以
"同步"方式实现：跨站点算力物理隔离（本项目设定），以及未来更普遍的"世界模型太大、
与策略训练无法同卡共存"。本文把不可避免的异步性形式化为研究对象：世界模型永远
是**陈旧的**——它在策略 π_{k−Δ} 的数据上训练，却要为 π_k 提供想象。我们提出双时
间尺度共进化框架（A800 持续重训隐空间世界模型集成，A100 做不确定性惩罚的想象
空间 RL，站点间只搬运压缩潜轨迹与 checkpoint），并给出以陈旧度 τ 为显式参数的
单调改进下界：当信任域半径随 τ 收缩、悲观惩罚随集成分歧度自适应时，改进可保证。
预注册实验在 LIBERO 与 LIBERO-Plus 上对照 SimpleVLA-RL、VLA-RFT、RIPT-VLA，
核心可证伪预测：τ≤24h 的共进化在 LIBERO-Long 上超过冻结世界模型 RL ≥8 点，
且移除悲观惩罚后想象收益与真实收益的背离 >15 点可被测量。

## 2. 科学问题

**三层问题栈**：

1. 表层（工程）：无互联双站点如何做世界模型在环 RL？
2. 中层（算法）：世界模型陈旧度 τ（其训练数据落后当前策略的迭代数/墙钟）如何
   进入策略改进保证？现有 Dyna/MBPO 理论假设模型与策略同步更新，τ>0 的情形
   没有任何已知界。
3. 深层（科学）：想象空间 RL 的收益中，多少来自世界模型的**新鲜度**，多少来自
   其**精度**？二者在算力约束下此消彼长（更频繁重训 = 每次训得更浅），
   最优刷新频率是一个此前没人问过的问题。

第 3 层是论文的灵魂：它把"两台机器不互通"从工程妥协升维为对一个普遍权衡的
首次量化——任何世界模型在环系统（包括单机）都面临刷新-精度权衡，我们的物理
隔离只是把它推到了极端可测的区间。

**空白确认**：模型陈旧度的形式化研究在 model-based RL 文献中未找到直接先例
（最接近的是持续模型学习与 replay 老化的讨论），该理论空白真实存在。

## 4. 方法概要

### 4.1 系统架构

```
A100 (SAPI)                                A800 (YYK)
──────────────                             ──────────────
策略 π_k + 想象 RL                          世界模型集成 {M_i} × 3
  │  想象 rollout ← M (陈旧 τ)                │  在 π_{k−Δ} 潜轨迹上持续重训
  │  不确定性惩罚 r − κ·disagree              │
  └─► 每日导出: 潜轨迹(压缩) ──────────────►  └─► 每日导出: WM checkpoint ──► A100
```

- 世界模型：隐空间动力学（非像素），基座用冻结 SimVLA VLM 特征 + 轻量动力学头
  （~100M × 3 集成），奖励用任务成功判别器（从演示终态帧对比学习）。
- 策略侧 RL：想象空间 PPO/AWR 于流策略——流策略的 RL 本身有技术选择
  （对数似然不可得），采用 advantage-weighted 回归或 SimpleVLA-RL 式采样重加权,
  Phase 0 先定此技术路线。
- 悲观惩罚：r̃ = r − κ·std_i(M_i 预测)，κ 随 τ 线性上调（理论驱动的设计）。

### 4.2 理论目标（命题草案）

**命题 1（陈旧度分解）**：想象误差 ≤ 拟合误差 ε_fit + L_M·W₁(d_{π_k}, d_{π_{k−Δ}})，
第二项即陈旧漂移，可由策略更新的信任域半径 δ 与 Δ 控制：W₁ ≤ Δ·C·δ。

**命题 2（陈旧感知单调改进）**：若每轮策略更新满足 KL ≤ δ(τ) 且
δ(τ) ∝ 1/(1+γ_s·τ)，则真实回报单调不减的充分条件成立（MBPO 界 + 命题 1 代入）。
推论：存在最优刷新频率 τ*，由重训预算-拟合精度曲线与漂移速率共同决定——
这给出第 3 层科学问题的理论回答，实验测 τ* 是否存在且与预测同阶。

## 5. 红队自我批判（为什么判定暂缓）

| # | 质疑 | 严重性 | 结论 |
|---|---|---|---|
| R1 | 算力：WM 集成×3 持续重训 + RL 多种子 = 300–400 GPU 天，双卡供给 4 个月才 240，且 RL 失败重跑概率高 | **致命** | 暂缓的直接原因。重启条件：≥6 卡或云预算 |
| R2 | 对手是持有集群的团队（VLA-RFT/Sword 系），共进化是他们的自然下一步，赛跑胜率低 | 高 | 但"陈旧度理论"角度他们没有动机做（集群使 τ→0），我们的差异化恰来自约束——若重启，理论先行挂 arXiv 占位 |
| R3 | 隐空间 WM 在 LIBERO 上的想象质量未知，可能连冻结版基线都立不起来 | 高 | 预置 Phase 0 门槛（见 §6），10 GPU 天内可判生死，重启时先跑 |
| R4 | 流策略的 RL 技术路线未收敛（社区在 2025-2026 仍在争论），技术选型风险叠加 | 中 | 等 P2 完成后我们对流策略的采样-选优机制有一手经验，BoK 能量可直接作为 RL 的 advantage 代理——P2 是 P1 的技术铺垫，顺序不能反 |
| R5 | 成功判别器作奖励 = 又一个可被 hack 的学习组件，双重 hacking 风险 | 中 | 判别器与 WM 不确定性双重悲观；LIBERO 有仿真真值可作诊断对照（真实奖励只用于评测不用于训练，保持故事成立） |

**综合判定**：方向的科学价值为五个方案中最高（理论空白真实、问题普遍），
但当前资源下失败概率 >60%。文档保全设计，重启条件明确：
（a）P2 发表建立流策略操作经验；（b）算力 ≥6×80G 或等值云预算；
（c）届时重新扫描共进化文献确认空白未被填补。

## 6. 实验设计（预置，供重启时执行）

### Phase 0：生死门（约 12 GPU 天）

| 编号 | 实验 | go/no-go |
|---|---|---|
| P0.1 | 冻结隐空间 WM 的想象保真度：WM rollout 的成功预测与真实 rollout 的相关性（100 episode 配对） | Spearman ≥0.6 → go；<0.4 → 换 WM 架构一次，再失败**砍** |
| P0.2 | 流策略 RL 微型验证：libero_spatial 单任务，仿真器在环（先不用 WM），AWR 式更新能否稳定 +5 点 | 能 → RL 技术路线成立 |
| P0.3 | Reward hacking 可测性：冻结 WM 上跑 RL，测想象收益 vs 真实收益背离曲线 | 背离显著（>10 点）→ 问题存在，本文动机成立；不显著 → 冻结 WM 已够好，共进化动机崩塌，**砍** |

注意 P0.3 的双向价值：它同时是"问题存在性证明"（论文 §1 的 motivating experiment）
与方向生死门。

### Phase 1–3（略述，重启时细化）

- Phase 1：τ 轴主实验（τ ∈ {0 模拟同步, 6h, 24h, 72h, ∞ 冻结}），LIBERO 四套件，
  对照 SimpleVLA-RL（仿真器上限）、VLA-RFT 复现、RIPT-VLA、SFT；
- Phase 2：消融（集成规模、κ(τ) 调度、潜轨迹 vs 全量数据传输、WM 重训深度）；
- Phase 3：τ* 存在性检验与理论界回填；LIBERO-Plus 泛化红利测量
  （SimpleVLA-RL 声称 RL 提升泛化——想象空间 RL 是否保留该红利）。

## 7. 预注册可证伪结论（重启时生效）

1. τ=24h 共进化 > 冻结 WM（τ=∞）≥8 点（LIBERO-Long）。
2. 移除悲观惩罚 → 想象-真实背离 >15 点（hacking 的直接证据）。
3. 存在内点最优 τ*（性能-τ 曲线非单调），且 κ(τ) 自适应组在所有 τ 上不劣于
   固定 κ。若性能随 τ 单调（越新鲜越好、无内点），命题 2 的权衡叙事被削弱为
   单边结论，论文降级。
