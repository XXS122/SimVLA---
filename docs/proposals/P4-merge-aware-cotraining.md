# P4 · 零通信约束下的可合并 VLA 协同训练

**MACT: Merge-Aware Co-Training of Vision-Language-Action Specialists under Zero-Communication Constraints**

- 目标会议：ICML 2027（主）；备选 NeurIPS 2027 / ICLR 2028
- 风险等级：低-中 ｜ 总算力：80–120 GPU 天 ｜ 墙钟：8–12 周（双站点天然并行）
- 独特优势：**两台物理隔离的服务器本身就是实验平台**——硬件约束即论文设定，无需模拟

---

## 1. 摘要

机器人操纵数据天然分散在无法互联的机构、站点与本体上，但现有分布式训练范式要么
要求中心服务器与同步聚合轮（联邦式），要么在训练全程对彼此毫不知情、事后合并时
跌出线性连通盆地（事后合并式）。本文研究一个此前未被形式化的设定：**训练全程零
通信，仅允许稀疏（天级）的人工 checkpoint 交换**。我们提出合并感知协同训练
（MACT）：两站点从共享初始化出发训练互斥任务子集，训练目标加入（i）对共享锚点的
邻近正则与（ii）低秩任务向量参数化，使两个专家在整个训练轨迹上被约束在近似线性
模式连通的区域内；天级的 checkpoint 交换实现为 DiLoCo 式 Nesterov 外步，其频率
成为被显式研究的实验轴。理论上给出合并模型损失关于任务向量互干扰项与局部锐度的
二阶上界，指出低秩参数化通过控制任务向量的谱重叠收紧该界。在 LIBERO（互斥套件
划分）与 LIBERO+CALVIN（跨域异构）两级设定上，MACT 的合并损耗 <3 点（相对联合
训练上界），而独立训练 + TIES/DARE 事后合并损耗 >15 点；外步频率从每日一次放宽
到仅结束时一次的退化曲线，量化了"通信量-合并质量"的权衡边界。

## 2. 科学问题

设两站点各持有数据分布 D_A、D_B（任务/本体/视角异构），从共享初始化 θ₀ 出发分别
训练 θ_A、θ_B。通信预算：训练全程共 R 次全量 checkpoint 交换（R ∈ {0, 1, 5, 30}，
对应"仅结束时合并"到"每日交换"）。目标：构造训练规则与合并算子 M，使

```
L(M(θ_A, θ_B)) − L(θ_joint) ≤ ε        （合并损耗）
```

其中 θ_joint 是不可实现的全数据联合训练。科学问题是：**合并损耗 ε 由什么量控制、
训练时能否主动最小化它、以及它随通信预算 R 如何衰减**。现有工作只在 R=∞（联邦/
DiLoCo）或 R=0 且无训练时机制（事后合并）两个端点上活动，中间地带是空白。

## 3. 相关工作深度对比

| 论文 | 链接 | 做了什么 | 关键不足（本文切入点） |
|---|---|---|---|
| DiLoCo (2023) | [arXiv:2311.08105](https://arxiv.org/abs/2311.08105) | 内层本地训练 H 步 + 外层 Nesterov 聚合，LLM 预训练通信降 500 倍 | ① H~500 步（分钟级同步），我们的物理设定是**天级**（H~30k 步），DiLoCo 未探索该区间且其收敛分析在大 H 下失效；② 同质数据分片，无任务异构；③ 从未在流匹配动作头上验证 |
| ATM (2024) | [arXiv:2411.03055](https://arxiv.org/abs/2411.03055) | 交替"微调-合并"提升任务向量正交性 | **最近邻工作**。但：① 中心化流程，合并即同步，无通信约束概念；② 无理论解释为何交替提升正交性；③ 视觉分类任务，无 VLA/机器人异构性 |
| 单次全局合并 (2025) | [arXiv:2507.06542](https://arxiv.org/abs/2507.06542) | 证明去中心化学习中最后一次全局合并出人意料地够用 | 必须正面引用并划界：其设定为同质数据 + 小模型 SGD；我们在**异构任务划分 + 0.8B VLA**上将展示单次合并显著劣于稀疏多次外步（Phase 1 的 R 轴实验直接回答），若结论相反则如实报告并归因 |
| FedVLA (2025) | [arXiv:2508.02190](https://arxiv.org/abs/2508.02190) | 首个联邦 VLA，双门控 MoE + 服务器聚合 | 需要中心服务器与频繁同步轮；MoE 改变了模型结构（合并后不再是单体 SimVLA）；隐私动机而非通信物理隔离动机 |
| MergeVLA (2025) | [arXiv:2511.18810](https://arxiv.org/abs/2511.18810) | 跨技能 TIES 合并 VLA 专家，真机验证 | 专家独立训练、对彼此无知，其结果恰好展示了跨域合并的断崖——但**没有提供任何训练时机制**防止漂移出连通盆地；本文把它的失败案例变成我们的对照组 |
| Task Arithmetic (2022) | [arXiv:2212.04089](https://arxiv.org/abs/2212.04089) | 任务向量加减编辑模型 | 事后编辑，无训练时保证；其成立条件（权重解耦）正是我们用低秩参数化主动构造的性质 |
| TIES / DARE | [arXiv:2306.01708](https://arxiv.org/abs/2306.01708) / [arXiv:2311.03099](https://arxiv.org/abs/2311.03099) | 剪枝-符号消解/随机丢弃解决合并干扰 | 事后修补干扰，而非训练时预防；作为我们所有设定下的合并算子基线 |
| Model Soups (2022) | [arXiv:2203.05482](https://arxiv.org/abs/2203.05482) | 同数据多超参微调的权重平均 | 依赖"同一任务多次微调"的天然连通性；异构任务划分下直接失效（Phase 0 将复现） |
| LMC (2019) | [arXiv:1912.05671](https://arxiv.org/abs/1912.05671) | 线性模式连通性与彩票假设 | 理论基础设施；本文将 LMC 从"观察到的现象"变为"被正则化维护的约束" |
| 可合并性预测 (2026) | [arXiv:2601.22285](https://arxiv.org/pdf/2601.22285) | 正则化过的模型更可合并（相关性研究） | 观察性结论，支持我们的前提；本文提供因果干预版本（显式加正则并测因果效应） |

**结论**：没有任何一篇同时具备（零通信约束 + 训练时可合并性机制 + 理论上界 +
VLA/流头设定）中的两项以上。ATM 与 2507.06542 是必须在相关工作里花整段处理的
两篇，处理方式已在表中预注册。

## 4. 方法

### 4.1 训练目标

站点 s ∈ {A, B}，参数化 θ_s = θ₀ + B_s C_s（低秩，秩 r，仅作用于动作头与 VLM
顶部若干层；VLM 底层冻结）。局部目标：

```
min_{B_s,C_s}  L_s(θ₀ + B_sC_s) + λ‖B_sC_s‖²_F        （邻近正则）
```

**为什么低秩 + 邻近能提升可合并性**（论文核心论证链）：二阶展开下合并损耗

```
L((θ_A+θ_B)/2) − ½[L_A(θ_A)+L_B(θ_B)] ≈ ⅛ (τ_A−τ_B)ᵀ H (τ_A−τ_B) + 交叉项
```

其中 τ_s = B_sC_s 为任务向量、H 为锚点处的曲率。邻近正则控制 ‖τ_s‖（界中二次项），
低秩参数化使 τ_A、τ_B 的列空间可被显式正交化（初始化 B_A ⊥ B_B），压低交叉项。
命题（待完整证明）：在 λ 足够大使训练停留在 θ₀ 的二阶邻域内时，合并损耗 ≤
C₁·‖τ_A‖‖τ_B‖·cos∠(τ_A,τ_B)·λ_max(H) + C₂·max‖τ_s‖²·λ_max(H)。

### 4.2 稀疏外步（通信协议）

每 T_out 步（默认 = 1 天 ≈ 30k 内步）：双方导出 checkpoint 人工交换 →
各自执行 Nesterov 外步 θ₀ ← θ₀ + β·Δ_avg（DiLoCo 式，但 H 大三个数量级）→
以新 θ₀ 为锚点重置邻近正则。R 是主实验轴：R=0（纯事后合并）、R=1（中点一次）、
R=5（每两周）、R=30（每日）。

### 4.3 合并算子

主用简单平均（理论对应物）；TIES、DARE、任务向量系数搜索作为算子消融——
预期结论：**MACT 训练下算子差异消失**（因为已在连通盆地内），这本身是方法有效的
间接证据。

## 5. 红队自我批判

| # | 质疑 | 严重性 | 对策 |
|---|---|---|---|
| R1 | LIBERO 四套件同域同本体，任务向量天然近正交，朴素 baseline 可能就赢——问题不存在 | **高（方向级）** | Phase 0.1 首先测朴素 split-merge 损耗；若 <2 点，立即升级异构度（LIBERO vs CALVIN，不同相机/动作空间归一化），直到损耗 >10 点再开始方法研究。异构度阶梯预先定义三档 |
| R2 | 低秩参数化限制专家容量，单站点性能先掉 5 点，合并损耗再小也没意义 | 中 | 汇报"绝对合并后性能 vs 联合训练"，不只报损耗；秩 r 消融含全秩+邻近组（拆开两个机制的贡献） |
| R3 | 2507.06542 的结论若在我们设定复现（单次合并足够），R 轴故事塌 | 中 | 这不是失败而是边界刻画：论文改讲"何种异构度下需要多少通信"，R×异构度二维矩阵本身就是贡献；预注册两种叙事 |
| R4 | 外步 β 与邻近 λ 强耦合，调参空间爆炸 | 低 | 沿用 DiLoCo 默认 β=0.9，λ 单轴扫描；预算已含 |
| R5 | "为何不直接轮流把数据拷来拷去"——数据搬运在很多真实场景确实可行 | 中（动机级） | 动机三支柱写清楚：数据主权/许可不可出站（医院、工厂）、数据体量 ≫ checkpoint 体量（TB 级 vs GB 级）、在线持续采集使数据快照永远过时；引 FedVLA 的隐私论证 |

## 6. 实验设计

### Phase 0：问题存在性验证（约 10 GPU 天，2 周）— **本方案最重要的阶段**

| 编号 | 实验 | go/no-go |
|---|---|---|
| P0.1 | 异构度阶梯 × 朴素 split-train-merge：(a) LIBERO 套件二分；(b) LIBERO vs 视角/颜色扰动版 LIBERO；(c) LIBERO vs CALVIN（[arXiv:2112.03227](https://arxiv.org/abs/2112.03227)）。各 30k 短训 + 平均/TIES 合并 | 找到损耗 >10 点的最低档 → 定为主设定；三档全 <5 点 → **砍方向**（问题在此规模不存在） |
| P0.2 | 在选定档上验证机制信号：测 τ_A·τ_B 内积、合并路径上的 loss barrier（Frankle 式线性插值曲线） | barrier 与损耗正相关（Spearman >0.5）→ 理论假设可信 |

### Phase 1：主实验（约 50 GPU 天，双站点并行 4 周）

- 设定：Phase 0 选定的异构划分；A100 训 D_A，A800 训 D_B，物理隔离，checkpoint
  经对象存储人工中转（真实计时，写入论文的系统部分）
- 方法组：联合训练（上界，需数据集中，仅为科学对照）｜独立训练+{平均,TIES,DARE}｜
  DiLoCo-大H（无邻近/低秩，隔离外步贡献）｜MACT 全量｜MACT−邻近｜MACT−低秩
- 通信轴：R ∈ {0, 1, 5, 30}
- 指标：D_A∪D_B 全任务成功率、合并损耗、单站点自任务成功率（检查 R2）、
  loss barrier、任务向量夹角随训练步的轨迹
- 3 seeds；成功率协议同 P2（50 trials/任务）

### Phase 2：消融（约 25 GPU 天，2.5 周）

秩 r ∈ {16, 64, 256, 全秩}；λ 扫描；B_A⊥B_B 初始化 vs 随机；外步 β；
合并算子 × 训练机制交叉表；不对称算力（A100 步数 = 2× A800，模拟真实站点差异——
这是审稿人问不到但实际部署必遇的问题，主动做）。

### Phase 3：分析（约 10 GPU 天）

- 逐层任务向量干扰热图（哪些层承载跨站点冲突——预期动作头 >> VLM 顶层）
- 合并模型的表征相似度（CKA）与两个专家的关系：插值还是并集
- 通信量-性能曲线的对数拟合：给出"每多一次交换买多少成功率"的经验率
- 失败案例：合并模型在哪个站点的哪类任务上退化最重

## 7. 预注册可证伪结论

1. 选定异构档上：MACT(R=30) 合并损耗 <3 点，独立+TIES >15 点。
2. 去掉邻近正则 → 损耗恶化 ≥5 点（机制必要性）；若不恶化，"训练时维护连通性"
   的核心命题被证伪，论文降级为 R 轴的实证研究。
3. 损耗随 R 单调下降且 R=1→5 的边际收益大于 R=5→30（次线性）；
   若 R=0 与 R=30 无显著差异，则 2507.06542 的结论在异构 VLA 设定下成立，
   如实报告为负结果 + 边界刻画。
4. loss barrier 与合并损耗跨所有配置正相关（ρ>0.5），支撑理论机制。

## 8. 审稿人攻击模拟

| 攻击 | 回应 |
|---|---|
| "ATM 已经做了 alternating merge" | ATM 无通信约束、无理论、无异构 VLA；我们把 ATM 的合并频率解释为 R=∞ 极限并在 R 轴上复现其行为，将其纳入框架而非并列 |
| "就是 DiLoCo 换个场景" | DiLoCo 大 H 失效是我们 Phase 1 的实测对照组；邻近+低秩是 DiLoCo 没有的机制且消融可分离其贡献 |
| "理论是二阶泰勒，太弱" | 定位为 guarantee-flavored analysis + 全部常数可实测（H 的谱、τ 范数、夹角），Phase 3 用实测量回填理论界并画预测-实际散点 |
| "为什么不用真实多机构数据" | LIBERO/CALVIN 划分是可控异构度的科学选择；真实多机构是结论的应用而非验证前提；限定 scope |
| "只有两个站点" | 两站点是最小可研究单元且对应真实硬件；S>2 的模拟扩展（单机顺序模拟 4 站点）作为附录实验，预算 +8 GPU 天 |
